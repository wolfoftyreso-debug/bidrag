# Revisionsrapporter

Genererade granskningar av systemet, sparade som fristående HTML. De är
ögonblicksbilder från den tidpunkt de skrevs — läs dem som historik, inte
som aktuell sanning. `docs/LIMITATIONS.md` är alltid den aktuella källan
för vad som återstår.

| Rapport | Innehåll |
|---|---|
| `tuv-revisionen.html` | Fullständig systemrevision i certifieringsstil (2026-08-18): scorecard 12 områden, avvikelseregister, spårbara bevis, domslut |
| `motforhoret.html` | Motrevision på direktivet "Ifrågasätt allt" (2026-08-18): jävsdeklaration, tre A-fynd (ångerrätt, art. 9, kunskapsbasens granskningsstämpel), reviderat domslut |
| `master-revision.html` | Master test & perfection audit — komponentklassificering, scorecard, dom |
| `redteam-rapport.html` | Red team-revision mot direktivens §1–39 |
| `forensisk-revision.html` | Forensisk genomgång av motorn och datakedjan |
| `ai-slutrevision.html` | Slutrevision av AI-motorn (Application Intelligence) |
| `arkitekturrapport.html` | Arkitekturgenomgång |
| `deploymentplan.html` | Driftsättningsplan |
| `sim30-utvardering.html` | Utvärdering av 30-användarsimuleringen |
| `utredning.html` | Inledande utredning av problemområdet |
